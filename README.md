# NK RTO Services Website

Free static website for NK RTO Services.

## Before publishing
1. Replace `YOUR-GITHUB-USERNAME` in `index.html`, `robots.txt`, and `sitemap.xml`.
2. Replace `YOUR_WHATSAPP_NUMBER` with the WhatsApp number in international format, without `+` or spaces.
3. Replace the Instagram, YouTube and LinkedIn placeholders.
4. Upload the repository to GitHub and enable GitHub Pages from Settings → Pages → Deploy from a branch → main → /(root).

The two supplied logo images are preserved in `assets/`.
